## inhalt

**KW 46 (9.–15. Nov 2026): 7 Meldungen, 3 Vorschläge**

Volle Woche: alle drei Engines haben geliefert (Unreal 5.9 Preview mit eingebautem MCP, Blender 5.3, Godot 4.8 beta 3), Anthropic hat Fable 5.2 ausgerollt, und bei den lokalen Modellen gibt es eine ernsthafte TTS-Alternative. Eine Warnung: das meistgeladene neue Bildmodell der Woche ist in der EU nicht lizenziert.

## Meldungen

**1. Unreal Engine 5.9 „MegaJam Preview“ (9. Nov): Unreal MCP im Editor, Unreal Assistant fährt Claude Code, Unreal Canvas mit Movie Render Graph als MCP-Tool**
Epic hat die 5.9-Preview eine Woche vor dem AI MegaJam veröffentlicht: Der Unreal-MCP-Server startet jetzt standardmäßig mit dem Editor (Port, erlaubte Origins und Toolset-Registry in den Editor Preferences), das neue Panel „Unreal Assistant“ kann statt Epics eigenem Dienst einen externen Agenten über das Agent Client Protocol fahren – offiziell unterstützt: Claude Code (`claude-agent-acp`), Codex, Cursor, OpenCode – und reicht ihm die Editor-Tools durch. „Unreal Canvas“ (experimentell) ist ein Arbeitsbereich für Text-, Bild-, Video- und Mesh-Generatoren mit eigenen API-Keys; das Begleit-Plugin „Unreal Canvas Bridge“ stellt Movie-Render-Graph-Renders als MCP-Tools bereit. Dazu ein experimentelles WebAssembly/WebGPU-Target, Lumen World Cache und neue Python-Bibliotheken zum Editieren von Blueprints, StateTrees und Dataflow-Graphen. Epic sagt offen, dass die Preview überwiegend von Agenten gebaut wurde, mit kürzerer QA als üblich.
Warum: Das ist genau der Hebel für die Broken-Shell-Cutscenes – Claude Code könnte MRG-Renders aus dem Chat anstoßen, statt über selbstgebaute Python-Brücken. Zwei Haken: Der MCP-Server hat laut Epic-Doku keine Authentifizierung (jeder lokale Prozess und jede localhost-Seite kann Editor-Tools aufrufen – auf einer Tailscale-Maschine Bind-Adresse prüfen), und MetaHuman 5.9 taucht in den Release Notes nicht auf. 5.8-Projekt nicht migrieren, Kopie nehmen.
Lizenz: Unreal EULA, unverändert. Quellen: https://dev.epicgames.com/documentation/unreal-engine/unreal-engine-5-9-release-notes · https://dev.epicgames.com/documentation/unreal-engine/run-external-ai-agents-in-the-unreal-assistant-panel-in-unreal-engine · https://forums.unrealengine.com/t/unreal-engine-5-9-megajam-preview/2852840

**2. Blender 5.3 (10. Nov): Gaussian Splats nativ, Vulkan Standard-Backend, Cycles-Dispersion, Python-API-Bruch**
Import von 3D Gaussian Splats aus PLY, SPZ und glTF als Point-Cloud-Daten, bearbeitbar in Geometry Nodes, gerendert in Workbench, EEVEE und Cycles (Relighting noch rudimentär). EEVEE läuft auf Windows (außer ARM) und Linux jetzt standardmäßig auf Vulkan; Cycles bekommt Dispersion im Principled BSDF und DLSS 4.5 Ray Reconstruction (NVIDIA-Treiber ≥ 620); Modeling bekommt Loop Tools und Quad Sphere als Primitive; glTF-Import kann KTX2-Texturen und Animation Pointers. Kompatibilitätsbruch für Skripte: `PropertyGroup.name` ist jetzt read-only, `GPUBatch.draw_instanced` nutzt `gpu_InstanceIndex`.
Warum: Splat-Import ist für Referenz-Scans von Orten (Smart-Garden-Laube, Fotogrammetrie für Inner-Shell-Umgebungen) interessant; Vulkan-Default kann auf der 5090 Viewport-Verhalten ändern. Du bist auf 5.2 LTS – 5.3 ist kein LTS, also nur parallel installieren, und Blender-MCP-/Addon-Skripte auf den `PropertyGroup.name`-Bruch prüfen.
Lizenz: GPL. Quellen: https://www.blender.org/releases/5-3/ · https://developer.blender.org/docs/release_notes/5.3/

**3. Godot 4.8 beta 3 (9. Nov): nur noch wenige Blocker, .NET 10 Pflicht**
74 Regression-Fixes von 51 Beitragenden, Feature-Freeze; der .NET-Build verlangt jetzt .NET 10 statt 8. 4.8 bringt insgesamt: Multi-Bounce-AO, Screen-Space-Contact-Shadows, Mip-Level-Texture-Streaming, animierte Decals (auch im Compatibility-Renderer), nativen `Trail3D`-Node, GDScript-Diagnosen, die nur den fehlerhaften Teil einer Zeile unterstreichen, schließbare/abdockbare Main Screens und experimentelles Symbol-Renaming. Nichts Neues bei High-Level-Multiplayer; einziger Netzwerkpunkt ist mbedTLS 4.1.0 (Breaking Change).
Warum: Für Inner Shell ist Texture-Streaming plus Contact Shadows der relevante Rendering-Gewinn bei stilisierter Grafik; Card-Sync ist nicht betroffen. RC steht kurz bevor – guter Zeitpunkt, das Projekt in einer Kopie gegen die Beta zu testen, bevor 4.8 stable kommt.
Lizenz: MIT. Quelle: https://godotengine.org/article/dev-snapshot-godot-4-8-beta-3/

**4. Claude Fable 5.2 und Mythos 5.2 (9. Nov): bis 30 % schneller, weniger Tokens, Fast Mode**
Anthropic nennt FrontierCode 2.0 49,1 % (Opus 5.5: 45,5 %), FrontierSWE v2 69,9 % (62,3 %), OSWorld 2.1 89,3 % (87,2 %); Fable 5.2 braucht bei Medium Effort weniger Tokens als 5.1 und liefert Ausgaben bis 30 % schneller, Fast Mode bis 2,5× (Claude Code, Platform, Google Cloud, Foundry). Preis Standard 8/40 $ pro Mio. Tokens, Fast Mode 16/80 $. Modell-String `claude-fable-5-2`; in Pro- und Team-Standardseats ist Fable für bis zu 50 % des Wochenlimits enthalten, Startaktion mit ein bis drei Extra-Resets. Anthropic empfiehlt weiter Opus 5.5 als Alltagsmodell und Fable für großen, offenen Scope.
Warum: Für Architektur-Reviews und lange Multiplayer-Sync-Fäden ist das dein Modell; wegen des 50-%-Deckels Opus 5.5 für Routinearbeit lassen. Claude Code 2.1.321 macht Fable 5.2 zum Standard-Fable-Modell mit 1M Kontext.
Quelle: https://www.anthropic.com/claude-fable-and-mythos-5-2

**5. Claude Code 2.1.321 → 2.1.325 (10.–14. Nov): Scheduled Tasks fragen vor Skills, Code Mode, Sandbox-Permissions**
Wichtig für deine Automationen: Seit 2.1.325 fragen `/loop` und Scheduled Tasks nach, bevor sie Skills mit `allowed-tools` oder Hooks ausführen – unbeaufsichtigt laufen sie nur noch, wenn `Skill(name)` in `permissions.allow` steht. Sandboxed Bash folgt jetzt dem normalen Permission-Flow (`sandbox.autoAllowBashIfSandboxed: true` stellt das alte Verhalten her). 2.1.323 bringt den experimentellen „Code Mode“ (Claude schreibt JavaScript, um seine Tools aufzurufen), einen 30-s-Heartbeat bei langen Hooks (Claude Desktop hält den Turn nicht mehr für hängend), `engines["claude-code"]` in `plugin.json`, Typecheck für TypeScript-Hook-Module und `MCP_SDK_GENERATION=v1` als Kompatibilitätsmodus. 2.1.321: Headless-Sessions laden geänderte `.claude/skills` nach, `claude remote-control --settings`.
Warum: Jeder Scheduled Task auf deinen Rechnern, der Skills nutzt, kann seit Freitag an einer Rückfrage hängen bleiben – Allowlist nachziehen. Code Mode ist für Godot-MCP-Sessions mit vielen kleinen Tool-Aufrufen interessant, aber noch opt-in.
Quelle: https://code.claude.com/docs/en/changelog

**6. ZONOS3-Mini (10./11. Nov): Open-Source-TTS mit 100M aktiven Parametern, 43 Sprachen inkl. Deutsch, Zero-Shot-Cloning**
Zyphra: 800M-MoE (64 Experten, Top-2, ~100M aktiv), Voice-Cloning aus bis zu 60 s Referenz oder 192-dim Speaker-Embedding, Steuerung von Emotion, Tempo und Betonung bis auf Wortebene, 44,1 kHz, Time-to-first-audio 80 ms (H100) bzw. < 150 ms (M3 Air). Läuft als CUDA-Server, C++/ggml (GGUF, CPU/CUDA/Vulkan), MLX und komplett im Browser über WebGPU; SGLang-Omni liefert einen OpenAI-kompatiblen `/v1/audio/speech`-Endpunkt mit Streaming.
Warum: Direkte Alternative zu Qwen3-TTS für NPC-Stimmen in Inner Shell und vor allem für Reachy Mini – Streaming mit < 100 ms Latenz bei winzigem VRAM-Bedarf lässt die 5090 für LLM und Whisper frei. Zweite TTS-Neuheit der Woche: Edge0 Audio8-TTS-Realistic-Air (13. Nov, 0,6B, 23 Sprachen inkl. Deutsch, Apache 2.0, Transformers), eher für Offline-Vertonung.
Lizenz: Gewichte Apache 2.0, Runtimes MIT. VRAM: nicht angegeben; Modell ≈ 800M Parameter. Quellen: https://huggingface.co/Zyphra/ZONOS3-Mini · https://huggingface.co/blog/Zyphra/zonos3-mini · https://huggingface.co/Edge0/Audio8-TTS-Realistic-Air

**7. MiniMax-H3-Image (10. Nov, nativ in ComfyUI) – Warnung: EU ist von der Lizenz ausgeschlossen**
33B-DiT, 16 Megapixel (4096² bis 6272×2688) ohne Upscaler, 6 Sampling-Schritte ohne CFG, Text-to-Image und Editing mit bis zu 16 Referenzbildern in einem Checkpoint; Trending-Platz 2 auf Hugging Face, Comfy-Org-Repack mit INT8 (21 GB) und W4A8 (12,5 GB) DiT, Qwen3-VL-32B-Textencoder in INT8 (27 GB) oder NVFP4 (15,7 GB), VAE 1,2 GB – technisch mit Offloading auf 32 GB machbar. Aber: Die „MiniMax-H3-Image Community License“ gilt nur im „Applicable Territory“, und das schließt EU, UK, USA und Südkorea ausdrücklich aus; Nutzung außerhalb ist „not authorized“, zusätzlich Autorisierungspflicht ab 1 Mio. $ Umsatz oder bei Hosted Services, Pflicht zur UI-Kennzeichnung und Verbot, Outputs zum Training anderer Modelle zu nutzen.
Warum: Für dich in Sachsen-Anhalt derzeit nicht nutzbar, weder für Konzeptkunst noch kommerziell – MiniMax verweist auf eine Einzellizenz auf Anfrage. Wenn Spaces oder Workflows damit auftauchen, Finger weg; Qwen-Image-2.1 und FLUX bleiben deine Kandidaten.
Lizenz: proprietär, Community License mit Gebietsausschluss (nicht kommerziell nutzbar in der EU). VRAM: nicht offiziell angegeben; ComfyUI-Template startet bei 4 MP für wenig VRAM. Quellen: https://huggingface.co/MiniMaxAI/MiniMax-H3-Image/blob/main/LICENSE · https://blog.comfy.org/p/minimax-h3-image-is-now-available

## Vorschläge

**1. ZONOS3-Mini auf der 5090 als Streaming-Stimme testen (1–2 h).** CUDA-Server aus dem Zyphra-Repo oder SGLang-Omni starten, deutsche Stimme aus 30 s Referenz klonen, Latenz und Qualität gegen Qwen3-TTS messen. Bringt: Entscheidungsgrundlage für die Reachy-Mini-Sprachschnittstelle (Streaming-Endpunkt ist OpenAI-kompatibel, also direkt an Open WebUI oder einen eigenen Godot-HTTP-Client anschließbar) und eine kommerziell saubere Stimme für Inner-Shell-NPCs.

**2. UE 5.9 Preview parallel installieren und Claude Code über Unreal Assistant an den Editor hängen (3–4 h).** Preview per Launcher neben 5.8, `claude-agent-acp` per npm, Broken-Shell-Projekt als Kopie öffnen, Unreal Canvas Bridge aktivieren und einen MRG-Render per Chat auslösen. Bringt: Wenn das trägt, entfällt die eigene Python-MCP-Brücke für Cutscenes. Vorher prüfen, auf welcher Adresse der MCP-Server lauscht (keine Auth); Claude Code nicht im Manual-Permission-Modus starten (bekannter Hänger laut Epic).

**3. Scheduled Tasks und `/loop`-Konfigurationen nach dem Claude-Code-Update durchsehen (0,5 h).** Für jeden Task mit Skill-Nutzung `Skill(name)` in `permissions.allow` eintragen, Sandbox-Bash-Verhalten entscheiden (`sandbox.autoAllowBashIfSandboxed`). Bringt: Automationen laufen wieder ohne Rückfrage durch.

## Beobachten

- Godot 4.8 RC: beta 3 nennt „nur noch wenige Blocker“, Stable vermutlich binnen Wochen; GDScript-Diagnostik und Trail3D dann testen.
- Unreal Engine 5.9 final: Preview ohne MetaHuman-5.9-Notes, Canvas und WebAssembly-Target experimentell; vollständige Release Notes und MetaHuman folgen.
- Unreal Canvas Bridge: Movie Render Graph als MCP-Tool – erst nach Praxistest für Broken Shell einplanen.
- Claude Code „Code Mode“ (2.1.323): experimentell, opt-in; abwarten, ob es Standard wird.
- MiniMax-H3-Image: Lizenz nennt „laufende Prüfung“ der EU-Lage – falls MiniMax das Gebiet öffnet, wird es zum ernsten Qwen-Image-Konkurrenten.
- Blender 5.3 Splat-Relighting: laut Release noch unreif; für Asset-Produktion auf 5.4 warten.
- Ollama 0.40.16 (9. Nov): `ollama launch claude` leitet Claude Code auf das gewählte lokale Modell, neues „ripple-preview“ (65B dense) – zu groß für 32 GB.
